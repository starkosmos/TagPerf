# SimPoint Simulation in gem5

This directory is used to run SimPoint of some benchmarks in
SPEC CPU 2006. Use script `setup.sh` a directory `se~` will be
generated in `gem5` directory. Use `[0-3]_*.sh` and gem5 will
automatically run the checkpoints extracted from
`simpoint.tar.gz`.

`simpoint.tar.gz` contains checkpoints of four benchmarks
`403.gcc`, `458.sjeng`, `471.omnetpp` and `483.xalancbmk` which
have high MPKI for indirect jumps. These checkpoints is
generated by tool
[MBAPIS](https://github.com/Shuiliusheng/MBAPIS).
